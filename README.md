### Hello! 👋

I'm Marcel Tannich, a WordPress consultant based in Vienna, Austria, with more than sixteen years in IT and software development. I solve complex WordPress problems: multilingual sites, WooCommerce, ACF/SCF, legacy codebases, plugin conflicts and the kind of debugging where the cause is not obvious.

I'm a member of the WordPress.org Plugins Team since April 2026, sponsored by SiteGround through Five for the Future. I review 600 to 700 plugin submissions a month and write code for the team's tools and for community plugins. Beyond that, I co-organise WordCamp Vienna, speak at WordCamps, and was Co-Lead of the Content Team for WordCamp Europe 2023.
